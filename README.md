# GymTrack

Εφαρμογή για Windows και Mac για να κρατάς την πρόοδό σου στο γυμναστήριο και στη διατροφή.

- **Σήμερα**: η σημερινή προπόνηση, θερμίδες και πρωτεΐνη, νερό, η εβδομάδα σου.
- **Προπόνηση**: το πρόγραμμα, καταγραφή σετ με κιλά και επαναλήψεις, χρονόμετρο ξεκούρασης, ρεκόρ, πρόταση πότε να ανεβάσεις βάρος, ιστορικό.
- **Διατροφή**: ημερολόγιο φαγητού ανά γεύμα με έτοιμα τρόφιμα (σπίτι, ντελίβερι, σνακ, ποτά) και δικά σου, θερμίδες και πρωτεΐνη, οδηγός.
- **Πρόοδος**: γραφήματα για κιλά, μέση, δύναμη ανά άσκηση και συνέπεια.
- **Λίστα**: λίστα για το σούπερ μάρκετ.

Οι στόχοι (θερμίδες, πρωτεΐνη) βγαίνουν από ηλικία, ύψος, κιλά, κίνηση και στόχο, και ξαναϋπολογίζονται σε κάθε νέα ζύγιση.

## Ποιο αρχείο κατεβάζω

Άνοιξε την [τελευταία έκδοση](https://github.com/demelistasos/GymTrack/releases/latest).

| Υπολογιστής | Αρχείο |
|---|---|
| **Windows** | `GymTrack-Windows-0.1.N.zip` |
| **Mac** | `GymTrack-Mac-0.1.N.zip` |

## Windows

1. Αποσυμπίεσε το zip (δεξί κλικ → «Εξαγωγή όλων…»), π.χ. στα Έγγραφα σε φάκελο «GymTrack πρόγραμμα».
2. Διπλό κλικ στο **GymTrack.exe**. Αν τα Windows πουν «Τα Windows προστάτευσαν τον υπολογιστή σας», πάτα **Περισσότερες πληροφορίες → Εκτέλεση οπωσδήποτε**.

## Mac

1. Άνοιξε το zip και σύρε το **GymTrack** στις **Εφαρμογές**.
2. Την πρώτη φορά: **Ρυθμίσεις συστήματος → Απόρρητο και ασφάλεια →** «Άνοιγμα ούτως ή άλλως».
   Αν πει ότι είναι «κατεστραμμένη», στο Τερματικό: `xattr -cr /Applications/GymTrack.app`

## Νέες εκδόσεις

Όταν βγαίνει νέα έκδοση, το GymTrack δείχνει πάνω πάνω «Υπάρχει νέα έκδοση». Με «Ενημέρωση τώρα» κατεβάζει το σωστό zip, ελέγχει το αποτύπωμά του (`SHA256SUMS.txt`), κλείνει και ξανανοίγει στη νέα έκδοση. Δεν γίνεται τίποτα χωρίς ερώτηση.

## Πού είναι τα δεδομένα

- `Έγγραφα/GymTrack/gymtrack-data.json`. Ο φάκελος αλλάζει από τις Ρυθμίσεις (π.χ. OneDrive).
- Κάθε μέρα κρατιέται αντίγραφο στο `Αντίγραφα ασφαλείας` (τα τελευταία 60). Προαιρετικά και σε OneDrive / Google Drive ή USB.
- Τα δεδομένα **δεν** ανεβαίνουν ποτέ στο GitHub.

## Για προγραμματιστές

Κάθε αλλαγή στο `main` φτιάχνει αυτόματα (GitHub Actions) μία έκδοση `v0.1.N` με zip για Windows και Mac, αφού περάσουν οι δοκιμές.

```
npm install
npm start        # τρέχει την εφαρμογή
npm run dist     # φτιάχνει το zip τοπικά (dist/)
npm test         # δοκιμές (χρειάζεται playwright)
```

```
main.js            παράθυρο, αποθήκευση, αντίγραφα, ενημέρωση
updater.js         ενημέρωση μέσα από την εφαρμογή (κατέβασμα, έλεγχος SHA-256, αντικατάσταση)
preload.js         η γέφυρα ανάμεσα στο παράθυρο και τον υπολογιστή
renderer/
  index.html       φορτώνει τα παρακάτω ΜΕ ΑΥΤΗ ΤΗ ΣΕΙΡΑ
  css/app.css      εμφάνιση (σκούρα / φωτεινή, προσαρμογή σε μικρές οθόνες)
  js/defaults.js   πρόγραμμα, τρόφιμα, λίστα, οδηγός
  js/core.js       δεδομένα, αποθήκευση, υπολογισμοί (θερμίδες, πρωτεΐνη, προτάσεις βάρους)
  js/ui.js         εικονίδια, παράθυρα, δακτύλιοι, γραφήματα
  js/pages/*.js    μία σελίδα ανά αρχείο
  js/update.js     μήνυμα νέας έκδοσης
  js/app.js        μενού, κουμπιά, εκκίνηση
tests/
  fixture.js       ψεύτικα δεδομένα δοκιμής (ΠΟΤΕ πραγματικά)
  unit.test.js     υπολογισμοί και ενημέρωση
  ui.test.js       κάθε σελίδα σε 3 μεγέθη, σκούρα και φωτεινή, και οι βασικές ενέργειες
```
